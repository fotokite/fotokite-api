# Fotokite API

The **Fotokite API** enables customers and partners to seamlessly integrate and automate Fotokite systems with their workflows. Its goal is to provide a flexible, high-level interface, with which you can easily control Fotokite systems and access real-time data, allowing you to build powerful, customized applications that improve operational efficiency and situational awareness.

The API offers two main types of interfaces:

- **HTTP-based REST endpoints** for standard requests and commands.
- **WebSocket connections** for live, dynamic data streams such as telemetry.
- **RTSP Streams** for video streams.

Together, these interfaces provide complete access to the core capabilities of the Fotokite system, empowering you to create solutions tailored to your unique needs.

## Examples

This repository includes a collection of examples to help you get started quickly. You’ll find focused examples that demonstrate specific API features, as well as interactive demos that show how to combine multiple endpoints and data streams for more advanced integrations.

## API Specification

The API is documented using the OpenAPI specification. You can find the specification files organized by version and release in the `./specification` directory. These files provide detailed, standardized documentation to help you confidently understand, implement, and integrate the API.

You can render the specification locally using Swagger, or explore it directly in our GitBook documentation at [developer.fotokite.com](https://developer.fotokite.com/fotokite-api), where it is fully rendered and ready to use.
